# Decision order log (AC-391, backend spec BE-1.6)

When two sources disagree, Capsule follows them in this order (backend spec §1.6):

1. The product spec and the owner's own dated decisions.
2. The Mangia Operations Final Lock training manual (how the work is done, and its defaults).
3. What the customer accepted and the facts of the event itself.
4. What the code and its tests do today (evidence of what is built, never a reason to do less).
5. Official provider documentation (Convex, Clerk, OpenStreetMap and the like).
6. Old-system records (TPP, Nowsta, Galley, Goodshuffle): evidence for moving data in.

Each line below is one place where two sources disagreed, which one Capsule follows, the rule number from the list above, and where the proof is. `tests/decision-order-log.test.ts` checks that every line names a rule from 1 to 6 and that every file it names exists.
